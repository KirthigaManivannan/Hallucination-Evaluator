How this demo works

Fair comparison and limitations
  • Same input. Both models get the identical question and system instruction, with the same temperature and answer-length limit, sent at the same moment.
  • Independent claim check. A separate search-enabled model reads both answers without knowing which model wrote which, picks key claims, and compares them with web sources.
  • Links are filtered. Only source links the checker actually retrieved are shown. A claim without a verifiable link is marked Unverified.
  • One question proves little. Results vary from run to run. This demo cannot say which model hallucinates more. That takes many questions and careful scoring.
  • Everyone can be wrong. Both answers and the checker may contain errors. Treat verdicts as a starting point for reading the sources.

Answers come from AI models through OpenRouter. Nothing here is professional advice. Questions are kept only briefly in server memory so the checker can read the answers.
